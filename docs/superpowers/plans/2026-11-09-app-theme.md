# Application Theme Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement these steps in this session.

**Goal:** Add a persistent top-right light/dark switch across Taskuary and contribute it upstream.

**Architecture:** A small browser preference module drives the root data-theme and React/MUI palette. Semantic CSS properties update custom styles without remounting active views.

**Tech Stack:** Existing React 18, MUI 6, Vite, node:test, Python test suite and browser smoke harness; no new runtime dependency.

**Spec:** ../specs/2026-11-09-app-theme-design.md

## Global Constraints

- Preserve the current light palette and application layout.
- No owner data in code, fixtures, screenshots or public descriptions.
- Commit generated taskuary/web assets, built from website sources.
- Do not replace the running Python installation or restart active agents.

## Review Focus

- Storage disabled or corrupt: switching still works.
- No saved preference: system changes update the theme.
- A choice in another tab updates both DOM and MUI.
- Theme changes retain active tasks, input and scene state.
- Light/dark foreground and semantic tint pairs stay readable.
