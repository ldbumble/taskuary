- The rail's task rows wear their workstream as a small label
- Workstreams read from six months of mail: a setup confirm screen, a weekly refresh, and a new hat noticed
- The Assistant drafts a bug report or a feature request when the owner asks
- The Advisor raises "Report this?" when Taskuary itself keeps failing one way
- Browser test: a wish, a bug and the Advisor's Report this? open the scrubbed draft
- Signing out of the CLI in the Agent pane no longer ends the task's agent
- The Advisor no longer calls a usage limit a broken report
- A genuine sign-in link is not a scam: triage weighs the sender on facts, not on mail banners
- Nothing closes a task automatically while work on it is still live
- Killer ideas: kinds that earn their place, a second look before raising, sure habits adopted and unsure ones asked once
- The second look asks join-or-restate, and a kind's record starts with it
- The second look keeps what the owner asked to be brought up, promises, and a date that has passed
- Yardsticks with more than one workstream, and a personal ask lights no work move
- STYLE per workstream, as a measured option: a draft reads how the owner writes there, else the shared style
- Unblock 0.3.10.9: the stranger-token stub takes sid, and the walk says why it skips the two report buttons
