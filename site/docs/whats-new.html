What each release changed, newest first. Ask the Assistant "what changed in the last update?" and it reads this page.

0.3.10.16 - 2026-11-02#

  • The task page's everyday asks join the audit, and three it refused or misled now land
  • The rail audit: 26 everyday asks about the work rail and its walk, and six it refused or misread now work
  • The everyday-asks audit covers the Connections page, and four things the Assistant got wrong there are fixed
  • A report's Run now and switch are on its row: the Assistant brings up the shelf, and reads each row by name
  • The Settings audit: 30 asks with Settings on screen, and four gaps closed
  • The Assistant on New: names the press each tab draws, sees every box, and fills a box a press draws
  • The Assistant works the Hub and the Board where they stand: Write one, a post by number, named menus
  • A phone asks yes or no only for what the row can do, and Watch it by phone is Watch it
  • A pip-installed or container Assistant reads the help pages and What's new too
  • The Assistant's self-knowledge audit: 24 asks, and the three gaps it found fixed
  • Regenerate the Assistant's tool page for the merged audits
  • What a real model wrote now lands: a task page's bare decision, a report by name, a CALL in tool markup
  • A report's miss still opens "No report by that name", and the exe check knows help is docs/site
  • A report act over the report on the table runs as it did: a row's handle is no report name

0.3.10.9 - 2026-11-01#

  • An Update is no longer held back by a second window onto the app
  • Personal is never learned from: a personal ask is an FYI, and nothing personal teaches or is raised
  • Readers get the item's workstream: the Advisor and agents read its own section, triage reads every one first
  • Memory hygiene: real people only, promises from sent words, bring-up from Done, lines expire, caps per workstream
  • The rail's task rows wear their workstream as a small label
  • Workstreams read from six months of mail: a setup confirm screen, a weekly refresh, and a new hat noticed
  • The Assistant drafts a bug report or a feature request when the owner asks
  • The Advisor raises "Report this?" when Taskuary itself keeps failing one way
  • Browser test: a wish, a bug and the Advisor's Report this? open the scrubbed draft
  • Signing out of the CLI in the Agent pane no longer ends the task's agent
  • The Advisor no longer calls a usage limit a broken report
  • A genuine sign-in link is not a scam: triage weighs the sender on facts, not on mail banners
  • Nothing closes a task automatically while work on it is still live
  • Killer ideas: kinds that earn their place, a second look before raising, sure habits adopted and unsure ones asked once
  • The second look asks join-or-restate, and a kind's record starts with it
  • The second look keeps what the owner asked to be brought up, promises, and a date that has passed
  • Yardsticks with more than one workstream, and a personal ask lights no work move
  • STYLE per workstream, as a measured option: a draft reads how the owner writes there, else the shared style
  • Unblock 0.3.10.9: the stranger-token stub takes sid, and the walk says why it skips the two report buttons
