# Build a spreadsheet

A good sheet is one its owner can change next month without breaking: they type into a few obvious cells and everything else follows.

## Before building

Know what question the sheet answers and who will keep it up. Ask where the figures come from and which period it covers if the task does not say; do not ask for numbers you can read from what you were given.

## Building it

- Inputs in one place, clearly marked, each with its unit. Everything derived is a formula that points at them - never a number typed where a formula belongs, never a figure buried inside a formula.
- One row a record, one column a field, a header row that stays in view. No merged cells in data, no blank rows splitting a table.
- Totals and checks that prove the sheet to itself: a column that should sum to another says so, and shows when it does not.
- Dates as dates, money as money, percentages as percentages - formatted so a glance reads them right.
- A sheet for each job (inputs, data, summary), named for what it holds. The summary comes first.
- Real figures from the owner's material. Where one is missing, an empty input cell with a note - not a guess that looks like data.

## Finishing

Open the file and change an input: the totals should move and no cell should show an error. Hand it over as a real spreadsheet file, and say which cells are theirs to fill in, what each sheet does and anything you assumed.
